# Intello website (light version)

Bilingual (Spanish / English) marketing website for Intello: cargo monitoring and business intelligence for logistics companies. Node.js (Express), server-rendered with the Intello design system, no client-side JavaScript.

```bash
npm install
cp .env.example .env   # optional for local use
npm start              # http://localhost:3000
npm test
```
