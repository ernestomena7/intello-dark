# Logos

Extracted as vectors from the brand manual (2024). Fixed fills — they do not inherit CSS colour.

- `intello-logo-on-navy.svg` — master stacked lockup for navy grounds: yellow #f6e71a mark, blue #4d72a6 wordmark.
- `intello-logo-on-blue.svg` — for blue grounds: yellow mark, navy #2d2d45 wordmark.
- `intello-logo-navy.svg` — all navy; on yellow and light grounds.
- `intello-logo-blue.svg` — all blue; on light grounds (the manual's cover version on paper).
- `intello-logo-white.svg`, `intello-logo-black.svg` — single-ink versions for photos and one-colour print.
- `intello-mark-yellow.svg`, `intello-mark-navy.svg`, `intello-mark-white.svg` — the symbol alone: favicon, app icon, avatars.
- `intello-wordmark-navy.svg`, `intello-wordmark-white.svg` — wordmark alone, only for the proposed horizontal lockup (see README › Logo).

Clear space 2x; minimum width 200px on screen, 5cm in print.
